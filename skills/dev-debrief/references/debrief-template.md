# 회고 양식

```markdown
# <사건> 회고

## 요약과 영향
- 사용자 또는 시스템에 발생한 영향:
- 기간과 환경:
- 현재 상태: 해결 / 완화 / 조사 중

## 타임라인
| 시각과 시간대 | 사건 | 근거 |
| --- | --- | --- |

## 원인과 기여 요인
- 확인된 직접 원인:
- 영향을 키우거나 탐지를 늦춘 조건:
- 추정과 추가 증거가 필요한 부분:

## 대응과 검증
수행한 조치, 관찰한 회복 증거, 남은 영향.

## 후속 조치
| 구분 | 구체적인 작업 | 완료 확인 방법 | 담당 | 기한 |
| --- | --- | --- | --- | --- |
| 예방 | | | 미정 | 미정 |
| 탐지 | | | 미정 | 미정 |
| 대응 | | | 미정 | 미정 |

## 참고 자료와 정보 공백
로그 위치, 커밋, PR, 모니터링 자료, 확인할 수 없었던 정보.
```

불필요한 빈 항목은 생략한다. 개인 정보·토큰·고객 원문 데이터는 복사하지 말고 사건을 설명하는 최소한의 요약과 접근 가능한 근거 위치를 사용한다.
