# 프로젝트 시작

1. 목적, 대상 플랫폼, 작업 위치, 지정된 언어·프레임워크·버전을 대화와 현재 폴더에서 확인한다. 결정되지 않은 스택이나 덮어쓰기 위험이 있는 위치는 확인한다.
2. 기존 저장소가 있으면 `AGENTS.md`, 패키지 관리 방식, 모노레포 구성과 유사 패키지를 살펴 그 구조 안에 추가한다. 내용이 있는 폴더를 초기화 명령으로 덮어쓰지 않는다.
3. 현재 제공되는 전문 생성 스킬이 요청에 맞으면 읽고 적용한다. 없으면 해당 도구의 공식 문서와 프로젝트 버전에 맞는 생성 절차를 사용한다. 특정 플러그인 설치를 선행 조건으로 요구하지 않는다.
4. 필요한 최소 소스, 의존성 및 잠금 파일, 실행 설정, 개발 안내를 만든다. 제품에 없는 인증·분석·결제·클라우드 리소스를 넣지 않는다.
5. 프로젝트에서 실제 사용하는 실행·빌드·검증 방법을 확인한다. 기본 동작을 검증하고 명령, 폴더, 결과를 전달한다. 실행할 수 없는 환경은 준비 완료와 실행 검증 완료를 구분한다.

생성 도구가 새 버전을 자동 선택한다면 호환성과 변경 내용을 확인한다. 전역 도구 설치, 유료 서비스 생성, 배포는 요청 범위에 있는지 구분한다. 저장소를 만들었다는 이유만으로 원격 저장소를 생성하거나 푸시하지 않는다.
