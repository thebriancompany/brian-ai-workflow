# 작업 인계

현재 채팅에서 계속할 수 있으면 기록 후 계속한다. 새 채팅은 사용자가 요청하거나 실제로 필요할 때만 사용한다. 다음 항목을 실제 값으로 채운다.

```markdown
# 작업 인계: <주제>

- 목표와 요청 범위:
- 작업 폴더 / 브랜치 / 확인한 HEAD:
- 계획 문서:
- 이미 결정한 사항과 이유:
- 완료 단계와 증거:
- 진행 중인 변경 파일:
- 원래 있던 사용자 변경:
- 실행한 검증: 작업 폴더, 명령, 결과, 검증한 코드 상태
- 미실행 또는 수동 확인 대기:
- 남은 작업과 차단 원인:
- 커밋·푸시·PR 상태 및 이미 받은 권한:
- 다음에 실행할 구체적인 작업:
```

재개할 때 기록만 믿지 말고 브랜치, 변경 파일, 마지막 검증 이후 수정 여부를 확인한다. 비밀값과 전체 로그 대신 필요한 오류 요약과 위치를 남긴다.
